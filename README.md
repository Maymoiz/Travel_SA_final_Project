# 🌍✨ ExploreSA — South Africa Travel Experience  
A modern, responsive, multi‑page travel website showcasing the beauty, culture, and destinations of South Africa.  
Built as an exam project for **Cavendish University** by **Moesha (CUU27692K)**.

---

## 🖤 Overview  
ExploreSA is a fully responsive tourism website designed to highlight South Africa’s top destinations, attractions, and travel experiences.  
The project includes interactive UI components, animations, filtering, search functionality, modals, a gallery lightbox, a mobile hamburger menu, and a clean, modern design system.

The website is built using **HTML, CSS, and JavaScript only** — no frameworks, no libraries, and no WebKit dependencies.
